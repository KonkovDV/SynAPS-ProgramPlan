# SynAPS-ProgramPlan changelog

## Не выпущено

- Документация для заказчика: README с картой требований F1–F5, руководство планировщика, форматы данных, справочник кодов, методология с источниками 2023–2026 годов, архитектура, качество и доказательность, данные и безопасность, пилот и развитие, глоссарий, обновлённая карта трассировки.
- Команда `export`: принятый план в MS Project XML; непринятый план не выгружается.
- Цель `--objective stability` доступна из командной строки.
- Импорт Excel: пустые необязательные колонки (`kind`, `status`, `type`, `source`, `code`, `reason`) получают значения по умолчанию, а не дают ошибку.
- Тест, который не даёт независимой проверке начать зависеть от решателя.

## 0.1.0 — 2026-10-05

Первый экспериментальный контур сводного плана программы ОКР на ядре SynAPS.

- Компиляция программы в задачу ядра: цепочки FS/0, остальные связи как FS/SS/FF/SF с лагами, пулы компетенций, отпуска и ремонты, вехи как мгновенные события.
- План принимается только после проверки ядра и независимой доменной проверки.
- Конфликты исходных планов, варианты A–E, объяснение сдвига, свидетель невыполнимости, перепланирование на новую дату статуса.
- Импорт и объединение MS Project XML, книга Excel, самодостаточный HTML-отчёт.
- Оценка риска P50/P80/P90 по принятому плану и HTTP-контур, который не отдаёт 200 на непринятый план.
- В SynAPS добавлены рёбра предшествования FS/SS/FF/SF; набор тестов FJSP сохраняется.
