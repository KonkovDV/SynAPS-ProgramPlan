# Модель угроз SynAPS-ProgramPlan

Продукт считает план внутри закрытого контура. Наружу даты не уходят, пока план не принят и хеши программы и плана не совпали. Ниже перечислены входы и то, что на них уже отклоняется.

## Точки входа

| Вход | Что приходит | Чем закрыт |
|---|---|---|
| Команды `import`, `solve`, `check`, `replan` | Файл программы, план, книга Excel, MS Project, Primavera | Проверка модели, независимая проверка, шлюз публикации |
| Вычислительный HTTP `/solve`, `/check`, `/risk` | JSON программы и плана | Размер тела, токен только по HTTPS с чужого адреса, частота, потолки работ, связей, ресурсов, горизонта и драйверов риска, по желанию отдельный процесс решателя |
| Рабочее место `serve` | Правки на диаграмме, журнал | Роли, локальный адрес или TLS, та же проверка плана |
| Журнал решений | Файл `.jsonl` | Цепочка хешей, печать, якорь, подпись HMAC при заданном ключе |

Подмена плана, у которого хеш не сходится с программой или даты не приняты, уже закрыта: `POST /check` отвечает 409, отчёт и выгрузка такой план не публикуют. Чужой адрес без токена получает 401. Тело больше 32 МиБ — 413. `SYNAPS_PROGRAMPLAN_RATE_PER_MIN` отвечает 429.

## Что добавлено к уже стоящим пределам

- Число работ, связей, ресурсов, исключений календаря, драйверов риска и длина горизонта. По умолчанию не больше 100 000 работ, 400 000 связей, 20 000 ресурсов, 100 000 исключений, 10 000 драйверов и 8 000 дней. Горизонт раньше 2000-01-03 отклоняется. Программа сверх предела не принимается в модель.
- Имена в отчёте. Данные страницы встроены как JSON, в котором `<`, `>` и `&` записаны экранированием Юникода. Имя из Excel, MS Project или Primavera не закрывает блок сценария.
- Книга Excel. Перед чтением архив проверяется: не больше 64 частей, не больше 32 МиБ в распакованном виде и не больше чем в 100 раз относительно сжатого размера. Книга, которая раздувается сильнее, не открывается.
- Решатель в отдельном процессе. Если задан `SYNAPS_PROGRAMPLAN_MEMORY_MB`, расчёт HTTP идёт в дочернем процессе. Когда его рабочий набор превышает потолок, процесс останавливается и сервис отвечает 503. Потолок времени процесса — лимит решателя плюс 30 секунд, иначе 504. Без этой переменной расчёт идёт в том же процессе, как и раньше.

- Политика страницы. Сценарий отчёта разрешён по хешу SHA-256 текста, сценарий рабочего места — по одноразовому ключу ответа. В политике нет `unsafe-inline` для сценариев. Стили остаются с `unsafe-inline`: подсказка, тепловая карта и цвета диаграммы задаются из сценария, а хеш рядом с `unsafe-inline` заставил бы браузер это разрешение отбросить. Чужой стиль может изменить вид страницы и не может выполнить код. Внешние адреса по-прежнему запрещены.

Это пределы прототипа, а не аттестация по требованиям регулятора. Прогон на Astra Linux и РЕД ОС выполняется на самой этой системе и в этот документ не записывается заранее.
