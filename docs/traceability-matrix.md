# Трассировка F1–F5 → SynAPS-ProgramPlan 0.1.0

Уровень: эксперимент. Это карта того, что код делает сейчас, а не документ сдачи заказчику.

| Требование | Где | Чем покрыто | Чего нет |
|---|---|---|---|
| F1 сводный план | `model.py`, `merge.py`, `io/mspdi.py`, `io/excel.py` | тесты импорта XML и кругового Excel | Primavera XER, MPP, 1С |
| F2 связи, вехи, сроки, лимит сдвига, заморозка | `compiler.py`, ядро `PrecedenceEdge`, `disrupt.py` | FS/SS/FF/SF, веха в день завершения, pinned, отпуск | политика прерывания работы через выходные |
| F3 конфликты и риск срыва | `conflicts.py`, `quality.py`, `cpm.py` | перегрузка, общая конкуренция, отрицательный резерв, качество данных | подтверждение экспертом на данных заказчика |
| F4 варианты | `scenarios.py` | A–E отдельными решениями, дедупликация одинаковых дат | набор решений из одного вызова ядра |
| F5 Гант, загрузка, причины | `report.py`, `explanations.py`, `api.py` | HTML без сети, причины сдвига, HTTP 200 только для принятого плана | роли, журнал решений, база, перетаскивание |

Проверка, без которой план не публикуется: `outcome.ok` = допустимый статус решателя, чистая проверка ядра и ноль жёстких нарушений `checker.py`.
