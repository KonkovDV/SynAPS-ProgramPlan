## Сквозные требования плана

| Инвариант | Как обеспечен | Чем проверен |
|---|---|---|
| Ни один план не попадает в отчёт или интерфейс без `outcome.ok` | Двойная проверка в `planner.py`, публикация через `publish.py`. Отчёт, рабочее место, экспорт, риск и HTTP отказываются от непринятого плана. Правка проверяется тем же `checker.py`. Вариант R публикуется только при `outcome.ok`. Восстановленный после перезапуска вариант проверяется заново | `test_no_false_accepts_under_random_shifts`, `test_rejected_plan_is_not_a_risk_baseline`, `test_export_refuses_a_plan_that_was_not_accepted`, `test_solve_rejects_an_impossible_deadline`, `test_infeasible_repair_is_not_published`, `test_unknown_task_or_rejected_base_is_refused`, `test_report_export_and_cli_check_do_not_publish_unaccepted_dates` |
| `INFEASIBLE` — только при доказательстве | `_claim(..., proof)` и признак `restricted`: урезанная модель этот вердикт не получает | `test_impossible_deadline_is_proven_infeasible`, `test_unproven_infeasibility_is_not_claimed` |
| `OPTIMAL` на j30 совпал с известным оптимумом | `_claim` ставит `OPTIMAL`, когда статус CP-SAT — `OPTIMAL` | `benchmarks/psplib_j30.json`: 472 таких плана, у всех длительность равна известному оптимуму |
| Независимая проверка не зависит от решателя | `checker.py` не импортирует компилятор, планировщик и ядро | `test_checker_stays_independent_of_the_solver_path` |
| Воспроизводимость | Детерминированный CP-SAT, хеши в доказательной базе, общие случайные числа в риске | `test_same_seed_same_plan_hash`, `test_same_seed_same_quantiles` |
| SynAPS без форка, по коммиту | Зависимость по полному SHA | `test_synaps_pin_is_a_commit_and_matches_the_published_files` |
| Решатель без обобщённых связей отказывает | ALNS и RHC на такой задаче возвращают `precedence_edges_unsupported` и в команду не выведены | `test_alns_and_rhc_do_not_encode_generalized_links` |
| Обезличивание и происхождение | `scripts/anonymize_program.py` заменяет имена кодами и сдвигает все даты на одно число дней, соответствие кодов не пишет. `out/` в `.gitignore`. У программы есть `provenance`, оно переходит в план и на первый экран отчёта. PSPLIB в репозитории не хранится | `test_names_disappear_and_every_date_moves_by_the_same_number`; [данные и безопасность](security-and-data.md) |
| ИИ не создаёт ограничения и не меняет план; объяснения — из фактов | Объяснения собираются из причин итогового плана. Команда `ask` по умолчанию выключена и ограничений не добавляет. Правки делает человек, их проверяет `checker.py` | `test_yandex_is_off_without_a_key`, `test_a_statement_without_a_known_fact_is_dropped`; [методология §8–9](methodology.md#8-объяснения) |
| Решения прослеживаемы | Журнал с хеш-цепочкой, пользователем, ролью, хешем плана и входа. Печать файла ловит обрезку и замену журнала. Подмена журнала вместе с печатью ловится якорем `journal --anchor`. Если задан ключ, запись подписана HMAC | `test_journal_chain_detects_edits`, `test_journal_witness_catches_a_cut_tail_and_a_replaced_file`, `test_a_wrong_signature_is_rejected`, `test_report_with_risk_and_journal_command` |
| Нет утверждений вне реестра | `CLAIMS_REGISTRY.md`, `BANNED_CLAIMS.txt` | `scripts/lint_claims.py` в CI |
| Противоречивые максимальные задержки, имена в отчёте, чужой HTTP | Положительный цикл максимальных лагов ищется по всему графу, алгоритмом Беллмана–Форда. JSON отчёта экранирует `<`, `>` и `&`. Вычислительный HTTP с чужого адреса отвечает только по HTTPS | `test_each_link_type_rejects_a_proven_positive_cycle`, `test_imported_names_cannot_close_the_report_script`, `test_remote_bearer_over_plain_http_is_refused` |
| Изделие и опытный экземпляр | Экземпляр ссылается на ресурс ёмкости 1, работа его занимает; два испытания одного экземпляра не пересекаются | `test_one_prototype_cannot_take_two_tests_at_once`, `test_a_named_article_must_be_occupied` |
| Записка языковой модели | `ask` выключена без ключа и каталога; читает только принятый план; фраза без известного факта отбрасывается | `test_yandex_is_off_without_a_key`, `test_an_unaccepted_plan_is_not_read`, `test_a_statement_without_a_known_fact_is_dropped` |
