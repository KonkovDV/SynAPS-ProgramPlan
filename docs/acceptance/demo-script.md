# Демонстрация на 15 минут

Учебная программа из четырёх ОКР. Каталог `out/` в git не входит. Команда `demo` собирает отчёт, риск и пример невыполнимого срока.

## 0–2 минуты. Что показываем

Сведение нескольких ОКР — одной командой. Общий стенд виден до оптимизации. Невыполнимый срок сопровождается набором требований и фразой, какое из них достаточно ослабить. После правки видно, сколько работ сдвинулось по связям, сколько на общем ресурсе и сколько не связано с правкой.

## 2–7 минут. Сводный план и варианты

```text
SynAPS-ProgramPlan demo --projects 4 --time-limit 8 --risk-runs 40 --out-dir out/demo
```

Открыть `out/demo/report.html`. Показать конфликты до оптимизации, диаграмму принятого плана и сравнение вариантов. Вариант со вторым стендом и вариант без одной ОКР публикуются вместе с принятым планом. В отчёт попадают только даты с `outcome.ok`.

## 7–10 минут. Невыполнимость

Открыть `out/demo/report_infeasible.html` и `out/demo/witness_infeasible.json`. Фраза «Достаточно ослабить любое из них» значит: снятие одного требования из набора делает программу выполнимой. Для сроков рядом есть дата, до которой срок нужно перенести.

## 10–13 минут. Импорт с отчётом потерь

Чистый XML: `import file.xml --strict --out out/demo/imported.json`. Код 0 — программа записана.

Файл с ограничением, которое контур не переносит (ALAP, материальный ресурс, работа уровня усилий): та же команда с `--losses out/demo/losses.json`. Код 2, программа не создаётся, в JSON видны код, объект и действие `skipped`, `approximated` или `clamped`.

Разные имена одного стенда сводит `--aliases names.csv` с колонками `alias,canonical`. Похожие имена без строки в таблице остаются в отчёте отдельными ресурсами.

## 13–15 минут. Выгрузка принятого плана

```text
SynAPS-ProgramPlan export out/demo/program.json out/demo/plan_A.json --out out/demo/plan.xml
```

В XML — проверенные даты, связи, ресурсы, назначения, директивный срок и хеш плана в примечании. Команда пишет только принятый план.
