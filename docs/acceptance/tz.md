# Техническое задание на SynAPS-ProgramPlan

Поставка лабораторного стенда: сводный план программы ОКР с двойной проверкой, вариантами, риском и журналом решений.

## 1. Назначение

Заказчик — Объединённая двигателестроительная корпорация. Запрос №1 — система формирования сводного плана программы ОКР с учётом общих специалистов, стендов, связей и сроков. Карточка запроса, его функциональные требования и ожидаемый эффект разобраны в [`docs/pilot-and-roadmap.md`](../pilot-and-roadmap.md).

Свести несколько планов опытно-конструкторских работ в одну программу, найти конфликты за людей и стенды, построить допустимый сводный план и несколько альтернатив, оценить разброс сроков и оставить прослеживаемое решение человека.

Расчёт выполняется в закрытом контуре. Отчёт открывается без внешней сети.

## 2. Функции

| Код | Функция | Чем подтверждена |
|---|---|---|
| F1 | Загрузка и объединение планов ОКР из MS Project XML, MPP/MPX, Primavera P6 XER и Excel | Тесты импорта, слияния, отчёта потерь и `--strict` |
| F2 | Связи четырёх типов с лагами, вехи, директивные и плановые сроки, закрепление, заморозка, отпуска и ремонты, опытный экземпляр на ресурсе ёмкости 1 | Тесты планировщика, календаря и экземпляра |
| F3 | Конфликты исходных планов и оценка разброса сроков по принятому плану | Тесты конфликтов и риска |
| F4 | Несколько вариантов плана и их показатели | Тесты сценариев, включая приоритет ОКР |
| F5 | Диаграмма, загрузка, причины переносов, ручная правка, журнал решений | Тесты рабочего места и журнал |

План попадает в отчёт, экспорт и ответ HTTP 200 только после двойной проверки. Независимая проверка не использует код решателя.

## 3. Состав поставки

Импорт с отчётом потерь, общие ресурсы, изделие и опытный экземпляр, CP-SAT и жадный диспетчер, варианты A–E, P и R, свидетель невыполнимости, оценка риска, рабочее место с ролями и журналом, экспорт принятого плана в MS Project XML с базовым планом 0 и границами горизонта. Записка языковой модели в расчёт не входит и по умолчанию выключена. Выгрузка 1С на пилоте идёт через MSPDI или книгу Excel по [`docs/data-format.md`](../data-format.md). Показ на учебной программе — [`docs/acceptance/demo-script.md`](demo-script.md).

Цифры, которые можно цитировать, собраны в `CLAIMS_REGISTRY.md`.
