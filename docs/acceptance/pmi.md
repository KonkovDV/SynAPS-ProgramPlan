# Программа и методика испытаний лабораторного прототипа

Статус: методика автоматических проверок и перечень того, что ещё должен сделать контур заказчика. Протокол испытаний у заказчика по этой методике не оформлялся.

## 1. Объект

Исходный код SynAPS-ProgramPlan и зафиксированный коммит ядра SynAPS из `src/synaps_programplan/versions.py`.

## 2. Автоматическая часть

На машине сборки, без данных заказчика:

```text
python -m pytest tests -q
python scripts/lint_claims.py
ruff check src tests scripts
mypy src
```

Ожидание: все тесты проходят, запрещённых формулировок нет, проверка типов без ошибок.

Соответствие функций и тестов — в `docs/traceability-matrix.md`. Академические прогоны, которые не входят в обычный `pytest`, потому что данные скачиваются отдельно:

- PSPLIB j30 — `scripts/bench_psplib.py`, результат `benchmarks/psplib_j30.json`;
- RCPSP/max j10, j20, j30 — тот же скрипт с `--ref`, результаты `benchmarks/rcpspmax_*.json`;
- синтетика до 2 688 работ — `scripts/bench_scale.py`, результат `benchmarks/scale.json`.

Наборы j60, j120 и MPLIB этой методикой пока не покрыты.

## 3. Что проверяет человек на стенде

1. Импорт обезличенного файла заказчика (MS Project или Primavera) и сверка числа работ, связей и ресурсов с источником.
2. Конфликты: эксперт отмечает, какие найденные конфликты подтверждаются.
3. Четыре варианта на этом файле: время до первого допустимого плана, до улучшенного и до набора вариантов. Цели пилота записаны в `docs/pilot-and-roadmap.md`.
4. Одна локальная правка в рабочем месте: сколько работ сдвинулось по связям, сколько на общих ресурсах и сколько без связи с правкой. Порог пилота относится к последней группе.
5. Журнал: принять и отклонить вариант, проверить `journal`, скопировать хеш последней записи вне системы и сверить `--anchor`.
6. Сеть: процесс на локальном адресе за прокси с TLS. Запуск на внешнем адресе без сертификата должен завершиться отказом.

## 4. Критерий приёмки прототипа как лабораторного

Автоматическая часть зелёная, а пункты раздела 3 либо выполнены и записаны в протокол, либо явно отмечены как невыполненные. Невыполненный пункт раздела 3 не заменяется успешным тестом на синтетике.
