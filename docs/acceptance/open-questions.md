# Вопросы, которые нельзя закрыть догадкой

Пока ответа нет, код выбирает более узкое поведение и записывает его в `LIMITS.md`.

1. Кто заказчик и есть ли подписанное ТЗ. В репозитории его нет. Внутренний черновик `docs/acceptance/tz.md` — не замена.
2. Размер боевой программы: число ОКР, работ, доля общих стендов. От этого зависит, хватает ли CP-SAT. ALNS и RHC ядра на обобщённых связях не запускаются.
3. Нужен ли режим секретности, при котором даже обезличенный файл нельзя выносить на машину сборки. Скрипт обезличивания у заказчика ещё не написан.
4. Какой обмен с 1С заказчик реально выгружает. Пока нет образца, отдельный формат не изобретается: путь — их выгрузка в MSPDI или в книгу Excel по `docs/data-format.md`.
5. Целевая ОС контура (Astra, РЕД ОС, ALT, Windows) и допустима ли Java только ради MPP. Установка на эти ОС здесь не прогонялась.
6. Порог пилота «четыре варианта за 2–5 минут» — на каком числе работ. На 96 работах укладка есть, на 2 688 работах CP-SAT с лимитом 60 с занимает около 157 с на один план, не на четыре.
